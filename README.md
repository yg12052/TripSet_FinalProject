 TripSet – Trip Planning Application

TripSet is an Android application designed to help users organize their trips in a simple and structured way.
The main idea behind the app is to concentrate all pre-trip planning in one place, instead of using multiple different apps or notes.

---------------------------------------------------------------------------------------------------------------------------------

Project Goal:

Before a trip, users usually need to:
- Manage general tasks (tickets, insurance, bookings)
- Prepare a packing list
- Keep important documents accessible

The goal of TripSet is to provide a clear and convenient interface that organizes all of this information per trip.

Features:

1. Trip Management
- Create a trip with destination and dates
- View a list of existing trips

2. General Tasks
- Add and remove tasks
- Mark tasks as completed

3. Packing List
- Add and remove items
- Track which items are packed

4. Documents
- Add PDF documents from the device
- Open documents directly from the app
- Delete documents

---------------------------------------------------------------------------------------------------------------------------------

Technologies:

- Kotlin
- Android (Fragments, RecyclerView)
- Firebase Authentication
- Firebase Firestore
